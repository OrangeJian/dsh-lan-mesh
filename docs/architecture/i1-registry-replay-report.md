# I1 请求幂等与审计（v0.4.25）

## 行为

openAgentRegistry.command(command,{requestId}) 支持显式稳定请求号。相同请求号及字段值返回第一次成功结果，revision和审计不再递增；相同请求号不同内容返回CONFLICT；每次重试先检查当前服务端authorize，历史成功不覆盖撤权。省略requestId仅供进程内旧调用兼容，会生成新号，不能得到跨调用幂等；后续任何远程入口必须要求显式requestId。

状态、请求指纹、历史结果与审计作为同一v2文件原子写入，成功rename后才发布内存。失败不占用请求号。审计记录操作/Agent/节点/时间/原结果，不记录localPath或完整命令。history只面向可信本地调用，不是对外读取API。

v0.4.24的v1数据保持只读加载，首次成功变更升级v2；不自动重写旧文件。重复requestId、无效指纹和外来权威等异常审计拒绝加载，不将损坏文件当空库。未添加自动裁剪，避免裁掉幂等记录后旧请求重新执行；大规模压缩归档策略另行实现。

## 验证

相关9项通过，包含跨重开重放、不同内容冲突、撤权、并发revision、写盘失败重试、旧格式升级、重复审计拒绝。全套结果待补。
