# UX-2b2 长消息折叠与复制（0.4.14）

基线0.4.13；沿用UX-0批准的长文约8行/代码约12行的默认阅读高度。保留完整Markdown输入与原始字符串，不截断代码围栏，不使用innerHTML。通过受限高度预览与展开/收起操作阅读全文；正文长度或换行超过门槛才折叠。附件和Skill卡片不进入折叠容器。

复制全文使用浏览器公开Clipboard API，复制原文含换行和Markdown；拒绝/不可用就近说明，不谎报成功。展开/复制只影响本条消息，失败后可再试；按钮键盘可达。没有文本的附件消息不显示复制按钮。

模型判定/复制错误先测试，独立组件导入验证和生产ChatBubble接入，保留原Markdown回归；模型/面板/兼容/完整检查、版本同步、本地提交、不推送。暂不扩展M6成果引用或原协议。
