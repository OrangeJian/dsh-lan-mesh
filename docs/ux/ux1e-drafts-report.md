本批保留同一页面/插件实例内按nodeId+sessionId+roomId隔离的未发送内容：文字/光标、精确成员mentions、Skill来源、固定文档版本、快速任务与任务表单；附件原File、预览URL、上传资源、上传状态和失败消息的重试messageId一起保留。离开Room仍卸载组件并停止轮询，不靠隐藏Room继续阅读维持草稿；已由用户开始的上传可以完成，返回不重复上传。
