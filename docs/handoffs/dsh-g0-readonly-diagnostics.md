# 本地 DSH 独立任务：只读诊断报告

本任务是G0辅助工作，不是重写网络或执行层。基线17cbb37、插件0.4.0；提交前检查实际分支和工作区，不覆盖Codex未提交的规划与测试修正。建议独立worktree执行，避免共享目录写入。

## 交付范围

新增 `scripts/mesh-diagnostics.mjs` 和 `docs/mesh-diagnostics.md`。不修改lib、index.js、client.js、package*.json、协议、配置或数据文件，不安装依赖、不启动DSH、不探测网络、不发送消息。不要新增第二套Host Bridge。

脚本只读本仓库和用户明确提供的实例目录，默认只输出当前仓库信息。支持 `--data-dir <显式目录>`、`--json`、`--help`；使用Node内置模块。不要自行遍历用户主目录或所有DSH实例。

报告包含：仓库包版本、Node版本；指定目录中identity.json/rooms.json/team.json等实际存在文件的存在性、字节数、JSON是否可解析。先核对store和team-store的真实路径，不猜文件名；不必深入解析或修复业务记录。文件缺失/权限失败/损坏必须各自明确。

隐私边界：不输出文件正文、环境变量、密钥、token、完整配置、聊天文本、绝对路径或用户名；不输出房间/成员名称或模型提示。只输出白名单状态字段；JSON解析异常用固定错误码，不直接输出可能含正文的异常message。读取大小设上限，超过明确标注未解析，不无限读入大文件。

退出码：0=只读检查无错误，1=指定输入或文件检查错误，2=参数错误。仅汇总不修复，不创建缓存/报告文件，不把“JSON可解析”称为业务账本完整或服务健康。

## 验证与回执

用临时夹具验证：无目录默认、正常JSON、缺文件、损坏JSON、超限、权限失败（平台可用时）、未知参数、敏感字符串不出现在输出、运行前后文件hash与目录清单不变。保留实际命令/结果。不要碰真实用户历史。

回执给Codex：base/head SHA、仅允许范围的diff、实际测试、输出示例、路径映射来源、未验证项。可在自己的分支提交；不推送或合并Codex分支，不发布。Codex负责独立复验后集成；文档或测试脚本单独交付不改变已加载插件版本。
