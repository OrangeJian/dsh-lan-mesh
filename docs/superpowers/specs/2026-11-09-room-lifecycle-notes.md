# 房间生命周期与个人偏好：已确认方向

2026-11-09，负责人确认继续推进。此文记录产品规则；具体协议/权限和并发接管实施方案尚需形成设计，当前M3附件批次继续。

- Leader可归档与恢复房间。归档默认隐藏，参与过的人类可从已归档列表查看；建议归档只读、停止新派发及自动唤醒。
- 每个节点保留自己的历史；退出不删除他人副本。删除本地记录为单独明确操作，不能被同步当作全局删除。
- 置顶、静音是本地偏好。静音降低人类收件箱和未读噪音，@例外需要在设置中明确；不应隐式停止已授权Agent执行。
- 历史参与资格与当前成员身份分开记录，不能只依赖当前members列表。
- 无负责人房间允许人类接手；暂时离线不等于无负责人。需要审计与并发争抢处理，防止两个节点同时接管。
- 房间管理者不自动获得Team执行Leader或其他节点执行授权，不自动接管运行中任务。

顺序：归档/恢复与个人置顶/静音 → 本地历史删除/退出语义 → 负责人移交与无主接管。不得通过现有retireRoom tombstone直接冒充归档。
