# G1 静态节点连接实施契约

复用现有HTTP、状态签名与Worker本机授权；仅添加可选owner配置staticPeers，不增加配对、信任或远程执行权限。每项为nodeId/address/httpPort/name，最多64项；地址支持IPv4和主机名，本批明确拒绝IPv6/URL/凭证/路径。nodeId与端点不能冲突。无配置保持现有行为。

静态地址优先于同nodeId的广播地址，防止广播覆盖手工固定目标。配置本身不证明在线：只有实际状态同步成功且响应nodeId一致才进入在线列表，失败或超过20秒未验证后消失；候选地址仍保留用于重试。拒绝身份不符的状态，不向该静态目标推送状态。认证/白名单/Team授权不因配置地址而改变。

任务：纯配置规范化与合并测试→接入配置和service候选/健康投影→真实localhost禁广播跨实例同步/身份不符/未授权拒绝→相关回归→独立本地提交。工作区暂停M6草稿不随本批发布，使用基线派生差异选择暂存并审查。

不把localhost称作跨网段实机验收；实际广播受限/跨网段场景仍待负责人设备验证。
